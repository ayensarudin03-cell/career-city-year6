📖 2. Grammar Toolkit

Want / Wants + to be

I / You / We / They want to be a pilot.
He / She wants to be a pilot.

Simple Present: Job Responsibilities

A chef prepares meals.
Teachers help pupils.
A pilot flies an aeroplane.

A / An + Occupation

I want to be a doctor.
She wants to be an engineer.
Use an before a vowel sound.

Because: Giving Reasons

I want to be a veterinarian because I love animals.
